# Waffles

This project was submitted to the Hack Club YSWS--[Waffles](https://waffles.hackclub.com/).

It uses vanilla HTML, CSS and JS to fetch and display the data of Characters and Locations in Rick and Morty Universe using the API: [rickandmortyapi.com](https://rickandmortyapi.com/).

There are two pages--characters and locations--each fetching the API differently and displaying it.

The styles across the pages are the same.
